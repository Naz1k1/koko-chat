# 历史消息展示分页验收

日期：2026-09-08。项目：koko-chat。此阶段扩展 Kotlin Compose Desktop 的历史展示能力，Java 21 / Spring Boot 3 / Netty / RabbitMQ 主链路、服务端接口和数据库迁移保持不变。

## 功能与操作

聊天默认显示最近 200 条本地消息。顶部“加载更早消息”按当前最小 seq 向前读取最多 50 条，插入列表前部；向上滚动可继续阅读。重复点击只执行一次，读取失败可重试，已到当前可见历史起点时显示边界提示。

用户展开的范围会在周期同步、消息推送和已读通知后保留；“查看最新消息”重新取最近 200 条并定位到底部。切换账号、会话或成员周期会重置范围，不能把上个会话的分页结果写到新页面。

列表使用消息 ID 作为稳定 key，向前插入时保留首个可见消息及其像素偏移。成员周期也参与定位状态的重置，相同群重新入群不会沿用旧周期滚动状态。

## 数据与进度边界

- 本地分页使用 `seq < beforeSeq ORDER BY seq DESC LIMIT 50`，返回时转为升序；查询同时限制账号数据库、会话、成员周期与 visibleFromSeq，复用 SQLite 联合唯一索引。
- 分页只改变展示范围，不写消息，不推进设备连续接收或用户已读位置。用户实际阅读仍由独立的焦点/可见区域判断触发 READ。
- 已缓存的历史可离线翻看。新设备继续通过原 HTTP 接口从当前成员可见起点正向补拉，固定 toSeq 上界；还未同步到本地的更早消息显示同步提示。
- 此阶段增加 SQLDelight 查询，没有新增表或迁移。SQLite 消息库仍为 v2，MySQL 仍为 V1–V3。

执行方式（先准备 JDK 21、deploy/.env、已构建后端 JAR 与中间件）：

```bash
KOKO_CHAT_RENDER_DIR=/tmp/koko-chat-history-preview \
  ./scripts/verify-desktop-auth.sh createDistributable packageDmg
```

脚本为新增联调账号 j/k 纳入随机前缀定向清理，结束时停止自己的临时后端进程。测试及安装包输出位于 build/target，不提交凭证、运行数据库或构建产物。

## 当前限制

本阶段为本地历史展示分页，尚未提供服务端倒序按需拉取接口。首次全量补拉成本仍随当前成员可见历史量增长。展开后内存中的消息范围随用户继续加载和新消息到来增长，返回最新或切换会话后收回；尚未实现固定内存的滑动窗口或大数据量性能验收。

Compose 测试使用实际布局与注入的列表滚动状态，未自动操作系统窗口或物理滚轮。本轮不改变其他功能阶段的历史验收记录。
